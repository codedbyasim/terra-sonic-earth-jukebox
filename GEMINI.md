## Mandatory Compliance Rules
1. **Zero NASA Branding**: Never include, generate, or modify any NASA official logos (Meatball or Worm), flags, or mission insignias in UI components, canvas visuals, slides, or documentation.
2. **Super Intelligence (SI) Disclosure**: Clearly document AI/SI-assisted engineering and procedural generation in UI footers, source file headers, exported `.json` metadata, and submission forms.
3. **Blind & Low-Vision (BLV) First**: Every control must include descriptive ARIA labels, full keyboard accessibility, `aria-live="polite"` telemetry updates, Web Speech API narration, and High-Contrast support.
4. **100% Original Procedural Audio**: All audio must be synthesized in real time via Web Audio API without third-party copyrighted audio samples.
5. **Scientific Fidelity**: All sonification parameters must derive directly from Computer Vision analysis (`getImageData`) of visual frames mapped to NASA SVS EIC datasets.
