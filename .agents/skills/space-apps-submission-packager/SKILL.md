# Space Apps Submission Packager Skill

## TeamX Details
- **Team Name**: TeamX
- **Members**: Asim Hanif (Team Leader), Maira Noor, Malaika Altaf, Tayyab Ali
- **Challenge**: The Earth Information Jukebox (2026 NASA Space Apps Challenge)

## Hard Eligibility Rules
1. **Slide Deck Limit**: Maximum **7 slides total** including Title and Introduction slides. Exceeding 7 slides disqualifies from Global Judging.
2. **Video Pitch Limit**: Maximum **30 seconds** (`[0:00]` Intro, `[0:02]` Challenge, `[0:05]` Project Name & Tagline, `[0:10]` How It Works + NASA Data, `[0:20-0:30]` Future Impact).
3. **Language**: All submission fields, slides, and docs must be in English.
4. **NASA Data Links**: Every NASA SVS link must use a complete `https://` URL and clear Link Text.
5. **SI Disclosure**: Explicitly disclose Super Intelligence tools used in development, metadata, and visual/audio synthesis documentation, while keeping zero NASA logos/insignias.
6. **Public Access**: Live URL and GitHub repository must require no login, password, or private permissions.
